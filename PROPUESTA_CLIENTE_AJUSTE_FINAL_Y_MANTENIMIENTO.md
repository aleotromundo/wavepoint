# Propuesta de cierre y mantenimiento
## WavePoint

**Fecha:** 11 de octubre de 2026

Hola,

Queríamos compartirte una actualización breve sobre el alcance de WavePoint y la forma más clara de dejar cerrado el trabajo realizado hasta ahora.

La propuesta inicial partía de una web estática informativa. Durante el desarrollo, el sitio fue creciendo para incluir una experiencia mucho más completa: catálogo de servicios, fichas individuales, dos idiomas, formularios de consulta, armado de viajes, cálculo de estimaciones, carrito, WhatsApp, clima, oleaje, cámaras en vivo, guía turística, páginas de colaboradores, asistente y una identidad visual propia.

El resultado nos gusta mucho y vemos que también te está gustando. Por eso queremos plantearlo de una manera simple y justa: **no recalcular todo el proyecto desde cero**, sino reconocer una parte del trabajo adicional y dejar la entrega actual cerrada.

## 2. Qué queda fuera de este cierre

El cierre de USD 300 contempla terminar y entregar el alcance actualmente construido. No incluye desarrollos nuevos de mayor alcance, como:

- Sistema de reservas con disponibilidad en tiempo real.
- Cobro online o integración de una pasarela de pago.
- Panel de administración o CMS.
- Base de datos de clientes y consultas.
- CRM o calendario de proveedores.
- Emails automáticos.
- Sistema de usuarios o cuentas.
- Nuevas secciones grandes o nuevos productos completos.
- Producción de fotografías o videos profesionales.
- Cambios estructurales pedidos después de aprobar la entrega.

Si en el futuro se necesita alguno de estos elementos, se puede cotizar por separado antes de comenzar.

## 3. Mantenimiento y mejoras mensuales

Para que el sitio no quede congelado y pueda seguir mejorando, proponemos un mantenimiento mensual. La idea es contar con una cantidad de horas y tareas previstas, en lugar de cotizar cada pequeño cambio desde cero.

### Opción recomendada: mantenimiento activo

| Concepto | Incluye |
|---|---|
| Precio mensual | **USD 120** |
| Tiempo incluido | Hasta 4 horas mensuales |
| Actualizaciones | Textos, precios, enlaces, imágenes y datos de servicios |
| Mejoras | Ajustes visuales, responsive y pequeñas mejoras funcionales |
| Revisión | Comprobación mensual de formularios, WhatsApp, enlaces y publicación |
| Entrega | Resumen breve de cambios realizados |
| Prioridad | Atención dentro de un plazo acordado |

Esta opción es la más equilibrada para WavePoint porque permite mantener actualizados los servicios, los precios, los colaboradores, las imágenes y la información turística sin convertir cada cambio en un proyecto separado.

### Otras opciones

| Plan | Precio mensual | Incluye |
|---|---:|---|
| **Mantenimiento básico** | **USD 75** | Hasta 2 horas: cambios pequeños de textos, enlaces, imágenes y revisión general |
| **Mantenimiento activo recomendado** | **USD 120** | Hasta 4 horas: mantenimiento, ajustes visuales y pequeñas mejoras funcionales |
| **Evolución continua** | **USD 200** | Hasta 8 horas: mejoras periódicas, nuevas secciones pequeñas y prioridad mayor |

Las horas no utilizadas no se acumulan indefinidamente. Se puede acordar que una parte pase al mes siguiente cuando exista una tarea concreta planificada.

### Trabajo adicional

Cuando una tarea supere el plan mensual, se informa antes de realizarla. Como referencia:

- Hora adicional: **USD 35**.
- Nueva funcionalidad grande: cotización independiente.
- Gastos de terceros, servicios pagos, dominios o proveedores externos: no incluidos salvo que se acuerde expresamente.

---

## 4. Qué tipo de cambios puede cubrir el mantenimiento

El mantenimiento mensual puede utilizarse para:

- Actualizar precios y temporadas.
- Cambiar descripciones de servicios.
- Agregar o reemplazar imágenes.
- Actualizar información de colaboradores.
- Corregir traducciones.
- Ajustar textos de la guía.
- Revisar botones, enlaces y formularios.
- Mejorar el comportamiento en notebook o móvil.
- Ajustar el carrito y los mensajes del armador.
- Revisar que las cámaras y datos externos sigan funcionando.
- Mejorar el asistente y sus respuestas.
- Incorporar pequeñas mejoras de navegación o presentación.

La intención es que WavePoint pueda seguir evolucionando de forma ordenada, sin que cada ajuste menor requiera volver a discutir todo el proyecto.

---

## 5. Forma de trabajo propuesta

1. Se recibe el pedido de cambio por mensaje o en una lista mensual.
2. Se agrupan tareas de contenido, visuales y funcionales.
3. Se confirma si entran en las horas del plan.
4. Se realizan los cambios en una versión de trabajo.
5. Se revisan en la web publicada.
6. Se entrega un resumen breve de lo actualizado.

Para cambios de precios, condiciones, horarios o incluidos de las experiencias, la información debe ser confirmada por el proveedor antes de publicarse como definitiva.
