# WavePoint

Sitio web estático bilingüe de experiencias de surf, turismo y colaboradores locales en Tamarindo, Costa Rica.

## Continuidad del proyecto

Para continuar un trabajo, consultar [`NO_SUBIR_AL_SERVIDOR/documentacion/PROJECT_GUIDE.md`](NO_SUBIR_AL_SERVIDOR/documentacion/PROJECT_GUIDE.md) y, cuando corresponda, [`NO_SUBIR_AL_SERVIDOR/documentacion/SEGUIMIENTO.md`](NO_SUBIR_AL_SERVIDOR/documentacion/SEGUIMIENTO.md). El seguimiento registra avances, decisiones y pendientes; debe actualizarse con criterio cuando una tarea cambie alguno de esos puntos. Los cambios relevantes también se anotan en `CHANGELOG.md`.

La aplicación no utiliza framework ni build obligatorio: se sirve como archivos estáticos HTML, CSS, JavaScript, imágenes y videos desde la raíz.
