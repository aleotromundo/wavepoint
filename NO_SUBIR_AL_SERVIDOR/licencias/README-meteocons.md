# Meteocons assets

The weather panel uses selected Fill icons from Meteocons 0.1.0:

- Animated SVGs: `@meteocons/svg`
- Reduced-motion SVGs: `@meteocons/svg-static`
- Source: https://github.com/basmilius/meteocons
- License: MIT, included in `LICENSE`

Only the weather conditions used by WavePoint and the `water-tide-high` swell
icon are included here.
