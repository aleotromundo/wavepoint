# Fotos extraídas de Guía segunda parte

Colección de las 22 imágenes referenciadas en `NO_SUBIR_AL_SERVIDOR/Guiasegundaparte_`. Se descargaron desde Google Docs en la mayor resolución entregada por la fuente (`w2048`), sin reescalado ni recomprensión adicional. La resolución máxima disponible depende de cada original; consultar `manifest.csv` para dimensiones y hashes SHA-256.

Estas imágenes se conservan como material fuente y no forman parte de los archivos destinados al servidor público.

Para conservar la ubicación de cada foto, consultar `REFERENCIAS_FOTOS.md`. También se incluye `guia-segunda-parte-con-fotos-locales.html`, una copia adicional con los 22 enlaces reemplazados por referencias locales a estos archivos. El archivo original de la guía permanece intacto.
