# Biblioteca de imágenes / Image library

- `stays/` contains confirmed photos grouped by accommodation.
- `services/` contains service photos grouped by service; Canva retreat images are in `services/retreats/`.
- `hotels/` retains shared accommodation imagery; `hotels/stayandhotels4_resultado.webp` is assigned to Casa Aura.
- `stays/casa-aura/` contains photos assigned to Casa Aura; do not reuse them for another property.
- `stays/unverified/` keeps legacy building and pool photos whose property has not been reliably identified.

- `stays/` contiene fotos verificadas y agrupadas por alojamiento.
- `services/` contiene fotos agrupadas por servicio; las imágenes de retiros del Canva están en `services/retreats/`.
- `hotels/` conserva imágenes generales de alojamiento; `hotels/stayandhotels4_resultado.webp` está asignada a Casa Aura.
- `stays/casa-aura/` contiene fotos asignadas a Casa Aura; no reutilizarlas para otro alojamiento.
- `stays/unverified/` conserva fotos antiguas de edificios y piscinas cuya propiedad no se ha podido identificar con certeza.
