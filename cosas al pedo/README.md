# Cosas al pedo

Archivos que no tienen referencias activas detectables en el front-end actual, separados para revisión manual.

- Se conservaron aquí originales reemplazados por variantes WebP, respaldos, duplicados, material legado y assets no utilizados.
- Antes de borrar algo, conviene revisar si lo necesitás para una futura página, edición o respaldo.
- Los íconos meteorológicos dinámicos, la imagen social SEO y los recursos actualmente usados no están en esta carpeta.
